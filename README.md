### Installation Instructions for GitHub Pages
To host this project on GitHub Pages, follow these steps:
1. Clone the repository to your local machine.
2. Navigate to the repository directory.
3. Run `git checkout -b gh-pages` to create and switch to the gh-pages branch.
4. Ensure your HTML files are in the root of the repository.
5. Push the gh-pages branch to GitHub with `git push origin gh-pages`.
6. Go to the repository settings and enable GitHub Pages from the gh-pages branch.
